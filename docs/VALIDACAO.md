# Validação da versão 1.0.0

## Automatizada

- 14 testes locais aprovados em Node.js: domínio, hashes, cobertura e referências de toda a base.
- Verificação de sintaxe JavaScript, referências locais e manifesto aprovada.
- Build estático sem instalação de dependências.
- O workflow de CI inclui compilação e execução do Java original em JDK 17, além dos testes web.
