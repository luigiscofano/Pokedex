# Acompanhamento de tarefas

Use o GitHub Project [Pokédex](https://github.com/users/luigiscofano/projects/7) para acompanhar pedidos de trabalho neste repositório.

1. Antes de iniciar, procure a issue e o cartão correspondentes. Reaproveite o registro existente ou crie um item com o objetivo e um critério de conclusão verificável.
2. Adicione o item ao Project, se necessário, e atualize seu status quando o trabalho começar. Registre bloqueios e o próximo passo no próprio item.
3. Vincule o pull request à issue quando houver alteração no repositório. Se uma solicitação abranger mais de um repositório, registre em cada quadro a parte correspondente e inclua referências cruzadas.
4. Ao concluir, confira o critério de entrega, registre a evidência (teste, publicação, documento ou decisão) e atualize o cartão. Se a entrega ainda depender de revisão ou publicação, indique essa pendência.
