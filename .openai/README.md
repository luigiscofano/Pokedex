# Configuração de hospedagem

`hosting.json` associa esta instalação ao projeto Sites e define `dist/` como saída estática. O arquivo não contém credenciais. O ID identifica esta instalação; uma cópia independente deve criar sua própria identidade de hospedagem.

O código pode ser executado localmente sem usar esta configuração. Tokens de publicação nunca devem ser adicionados ao Git.
